🎓 GradeFlow API Documentation

Base URL (Local Server): http://127.0.0.1:8000

Assignment Management Endpoints

GET /api/assignments

Retrieves all assignment records from the database.

POST /api/assignments

Creates a new assignment record.

GET /api/assignments/{id}

Fetches a specific assignment by its ID.

PUT /api/assignments/{id}

Updates an existing assignment record by ID.

DELETE /api/assignments/{id}

Deletes an assignment record by ID.
