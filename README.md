# GradeFlow - Assignment & Grading Portal

A web application designed for students to submit assignments and instructors to review and grade submissions.

## Tech Stack
- **Frontend**: React with TypeScript
- **Backend**: FastAPI (Python)
- **Security**: JWT Authentication & Role-Based Access Control (RBAC)
